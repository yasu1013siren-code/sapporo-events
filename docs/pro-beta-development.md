# PRO βの更新とレビュー

## 構成

- `pro_beta.py`：既存SQLiteを読み取り専用で開き、今日を含む30日間のデータを生成。標準ライブラリのみ。
- `pro/template.html`：モバイル対応UI。JSONを埋め込むためAPI・追加サーバー不要。
- `data/pro.html`：実データから生成した試用ページ。GitHub Pagesの無料ページと同じディレクトリに追加。
- `sapporo_chuo_collector.py`：無料HTML生成後にPROを追加生成。PROが失敗しても無料レポートは更新される。全国公開予定映画は公開日当日以降に除外する修正も含む。
- `tests/test_pro_beta.py`：日付、別日/別会場の重複、読み取り専用、安全なURL/埋め込み、無料サイトの映画回帰テスト。
- `docs/pro-beta-trial.md`：店舗案内・質問項目・試用計画。送信や募集は実施していない。

## ローカル確認

```sh
python3 -m unittest discover -s tests -v
python3 pro_beta.py --today 2026-10-04
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765/data/pro.html`。日付指定は検証用。実運用の単体生成は `python3 pro_beta.py`。収集実行時は従来どおり `sapporo_chuo_collector.py` を起動し、無料ページ生成後に自動更新する。Windowsは `py -3.14 pro_beta.py` でもよい。

`data/pro.html` と `data/index.html` は同じ公開ディレクトリに置く。既存の公開方式・無料ページのURLは変えない。レビュー用PRは自動マージしない。無料ページへPROリンクを付けるのは試用準備・公開後でよい（このPRでは無料ページのナビを変更しない）。

## 日付・重複の方針

日本時間の生成日を基準に、確認できた期間が今日〜29日先と重なるものを採用。年省略は情報取得年に固定し、過去日を翌年に持ち越さない。年末年始の明示範囲は引き継ぐ。日付不明・無期限・不正日付は除外し件数を集計。記事公開日をイベント開催日として代用しない。映画は上映終了日が未確認のためPROの営業一覧に含めない。無料サイトの上映中カテゴリは維持。

同一の正規化タイトル・開始日・終了日・会場が一致する情報を統合し、情報元リンクを残す。タイトルだけでは統合しない。表記が異なる会場・タイトルの重複や同日同会場の異なる公演を完全には識別できない。URLのクエリは別イベントを識別し得るので削除しない。

地域は会場表記・既知施設名による分類。取得元名だけで中央区と推定しない。曖昧なものは「所在地確認待ち」。地域欄は厳密な距離や徒歩商圏ではない。

## βの限界と有料化前の作業

静的プレビューのため閲覧を有料会員に制限しない。980円は需要検証価格。認証、申込、決済、問い合わせ先、規約、情報元の商用利用条件、通知配信、回答回収先の確定は有料提供前に整備する。回答はブラウザからファイル保存する方式で、サーバーへの送信はない。

お気に入り・メモは端末のブラウザ内に保存。保存できないブラウザでは警告しCSV保存を案内する。更新を停止したページでも終了済み予定は閲覧時に除外するが、新規イベントや日程変更を取り込むには再生成が必要。

自動取得の全収集先への実アクセスは今回のテストでは行っていない。取得漏れや日付情報元の正しさは、試用中に人がリンク先で確認する。営業への参考文は固定の確認観点であり、集客影響度スコアや来客予測ではない。

## ブラウザテストの再実行

PlaywrightとChromiumが使える開発環境で、検証日固定のページを生成した後に実行する。

```sh
python3 pro_beta.py --today 2026-10-04
node tests/ui_pro_beta.cjs
```

通常はPlaywrightのChromiumを利用する。別の検証用Chromiumは `PRO_CHROMIUM_PATH` で指定可能。テストの画像は `docs/screenshots/` に出力される。ローカルファイルとして開き、ブラウザ内のテスト用データだけを操作する。生成ページに実運用の営業メモを入力する前に実施する。

詳しい結果は [検証結果](pro-beta-validation.md)、店舗試用の実施手順は [試用計画](pro-beta-trial.md) を参照。
