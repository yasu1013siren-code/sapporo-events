# 飲食店PRO β：10〜20店舗・2週間の需要検証

## 試用の目的と提供内容

札幌の飲食店が、イベント調査を短縮し、仕込み・シフト・告知に役立てられるかを確認する。将来価格は月額980円（税込）想定。2週間は無料で、カード登録・自動課金・自動更新は行わない。継続希望は契約や購入実績として数えない。

βで提供するもの：地域・7/14/30日間・種別・検索による絞り込み、開催日順の一覧、ブラウザ内のお気に入りと営業メモ、CSV、スタッフ共有用テキスト、回答JSONを保存できるアンケート。

無料の `data/index.html` と `data/upcoming.html` は引き続き利用できる。PROは `data/pro.html` の追加ページ。試用版は静的な公開プレビューで、有料会員専用の保護はない。自動通知、会員管理、課金、端末間同期、来客予測、終演時刻の取得は未実装。毎朝の確認は試用中に手動で行う。

## 対象店舗と募集の手順

目標15店舗、最低10・最大20。中央区の飲食店を中心に、すすきのの居酒屋/バー5、大通の飲食店/カフェ5、札幌駅周辺5を目安にする。各地域で1名は店長または仕込み/シフトの決定担当。既存の知り合いに偏らないよう、半数程度は普段情報収集ツールを使っていない店舗を選ぶ。同系列は最大2店舗にする。

担当者が送信先の許可と正しい連絡先を確認してから案内する。返信を受けた店舗だけに P01〜P20 の試用番号を割り当てる。連絡先と店舗名の対応表は公開リポジトリに置かない。未回答を「不要」と推定せず、参加数・有効回答数・継続意向数を分けて報告する。

## 初回案内（送信用の草案）

> 札幌の飲食店向けに、近隣イベントやライブ、催事、開店・閉店をまとめて確認できる「飲食店PRO β」を作っています。仕込み・スタッフ配置・告知の前に調べる時間を減らせるか、2週間の無料試用にご協力いただけませんか。
>
> 今回は地域・日付の絞り込み、お気に入り、営業メモ、スタッフに共有できるまとめをご利用いただけます。月額980円（税込）を想定していますが、試用中の課金や自動更新はありません。最後に5分ほど、役立った点と有料でも続けたいかを教えてください。
>
> 掲載状況や時間は情報元の確認が必要です。売上や来客数を保証するものではありません。試用URL・担当者の連絡先・開始日/終了日は、参加をご希望いただいた方へご案内します。

送信前に試用URL、担当者名、連絡先、開始日、終了日を実際の情報に差し替える。未公開PRのリンクを店舗に送らない。PRのレビューと公開準備後に募集する。

## 14日間の実施計画

| 日程 | 店舗が行うこと | 運営側が確認すること |
| --- | --- | --- |
| 開始前 | 参加同意、今の調査時間と情報源を回答 | 10〜20店舗の参加数、試用番号、URL、連絡先を確定 |
| 1日目 | 5〜10分で地域・期間設定。予定を1件保存 | スマホで開けるか、メモ/共有操作、日付・会場の誤り |
| 2〜3日目 | 営業前に確認。役立った情報と所要時間を記録 | 最新データを毎日生成。重複・終了済み・リンク切れを点検 |
| 4〜6日目 | 仕込み・配置・告知への利用を1回試す | 問題の再現条件を記録し修正。指摘を数える |
| 7日目 | 中間質問：使った回数・不足情報・継続理由 | 利用できていない店舗へ操作支援。回答を催促し続けない |
| 8〜13日目 | 週末前に共有用まとめを試す | 追加の利用事例を記録。通知需要は手動配信で別途検証可 |
| 14日目 | ページ末尾のアンケートを保存して担当者へ渡す | 集計、継続意向と実例を確認。試用終了を案内 |
| 終了後2日以内 | 必要なら5分のヒアリング | 継続・改修・保留を判定し、参加者へ結果を共有 |

開始日は未定。参加店舗が決まってから全店で同じ14日間か、店舗ごとの14日間かを決める。試用終了後の課金は別の申込・同意が必要。

## アンケート（ページにも実装）

1. 試用番号（任意）と業態。
2. 1週間に何回使ったか。
3. 1週間で情報を探す時間を何分短縮できたか（短縮なしは0）。
4. 最も役立った機能。
5. 月額980円（税込）なら：継続したい / 条件が合えば / 無料なら / 利用しない。
6. 実際に変えた判断と改善点（自由記述、個人情報不要）。

補足ヒアリング：「その情報がなかった場合どう調べたか」「実際に仕込み/シフト/告知を変えた例」「継続の条件」「欲しい通知の曜日・時刻」。回答ファイルの保存だけでは運営に届かない。担当者への受け渡しを明示する。

## 判定基準（試用前に固定する仮説）

有効回答が10店舗未満なら判断を延期。未回答率も報告する。指標は自己申告なので、ログで実測した値として扱わない。

| 指標 | 継続開発の目安 |
| --- | --- |
| 利用 | 回答店舗の60%以上が週3回以上利用 |
| 時間短縮 | 回答店舗の中央値で週15分以上短縮 |
| 有料意向 | 「継続したい」が有効回答の30%以上、かつ3店舗以上 |
| 営業への利用 | 少なくとも3店舗で具体的な判断変更例 |
| 品質 | 公開済み/終了済みの誤掲載、誤日付など営業判断を誤らせる既知問題を解消 |

満たした場合も需要が確定したとは扱わない。次に980円の実申込を別途提示して、申込率・継続率を検証する。「条件が合えば」は有料意向の確定数に含めない。

## 回答管理

回答JSONと店舗対応表はリポジトリにコミットしない。試用終了から30日で番号と連絡先の対応表・生回答を削除し、個人や店舗を特定しない集計のみ残す（別途保持の同意を得た場合を除く）。希望者の削除依頼に対応する担当者を事前に決める。
